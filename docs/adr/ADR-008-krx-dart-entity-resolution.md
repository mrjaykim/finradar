# ADR-008: KRX 상장폐지 데이터와 DART corpCode.xml 간 Entity Resolution 전략

## 상태
결정됨 (2026-07-27)

## 배경
ADR-007에서 확보한 `mart.delisted_company.stock_code`를 실제로 DART corpCode.xml과
매칭해보니, stock_code 단순 조인만으로는 불충분함을 발견.

## 검토한 대안 및 발견

**1. stock_code 단순 조인**
위험함이 확인됨. 종목코드 재사용 사례(예: 진로산업↔제이에스전선)가 발견되어, 다른 법인의
재무제표가 잘못 연결될 위험이 있었음.

**2. stock_code + corp_name 정규화 교차검증**
전체 1,751건 distinct `krx_isu_cd`에 적용한 결과:
- 패턴 A (corp_code 자체 없음): 402건 (23.0%) - DART가 오래된 상장폐지 법인을
  corpCode.xml에서 제외한 것으로 추정, 재무제표 확보 자체가 불가능
- 패턴 B (stock_code는 있으나 이름 불일치): 547건 (31.2%)
- 패턴 C (정상 매칭): 802건 (45.8%)

정량적 검증: 패턴 B와 C의 `is_financial_distress=true` 비율이 각각 74.2%, 74.7%로 거의
동일함을 확인 - 이름 불일치가 부실 여부와 무관한 별개의 원인(상호변경, 합병 등)임을
통계적으로 검증.

패턴 B(547건 중 실질부실 406건)를 원인별로 세부 분류:
1. 단순 표기 차이 (232건, 57.1%) - 영문 약칭↔한글 음역(LG→엘지), 스팩/리츠의 KIND
   약식명 vs DART 법정 정식명칭(다산리츠→다산자기관리부동산투자회사) 등
2. 상호변경 (59건, 14.5%) - KIND 공식 상호변경 이력으로 확인된 동일 법인
3. 합병·분할 (7건, 1.7%) - 은행/저축은행 등 금융업권의 피인수합병 추정
4. 종목코드 재사용 (0건) - KRX/코스닥은 폐지 종목코드를 재사용하지 않는 것이 원칙임을 확인
5. 원인 불명 (108건, 26.6%)

## 선택
- 카테고리 1(단순 표기 차이)과 2(상호변경)는 정규화 규칙 개선 및 예외 테이블로 구제
- 카테고리 3(합병·분할)과 5(원인 불명)는 원칙적으로 제외 (법인 정체성이 실제로
  달라졌거나 판단 근거 불충분)
- 최종 활용 가능 표본: 패턴 C(802건) + 카테고리 1(232건) + 카테고리 2(59건) = 최대 1,093건
  잠재 후보 (실제 구제는 정규화 규칙 구현 후 확정)

## 선택 이유
유사도 알고리즘(Levenshtein 등)에 의존하지 않고 카테고리별 명확한 증거(KIND 공식
상호변경 이력, delist_reason 키워드, 업종 특성, 상장일 시간 순서)를 기반으로 판단해
데이터 오염 위험을 최소화함.

## 트레이드오프
패턴 A(402건)와 카테고리 3, 5(115건)는 학습 데이터에서 제외되어, 1,751건 중 최종
활용 가능한 표본은 최대 1,093건(62.4%) 수준. 카테고리 5는 자동 분류 신호로 못 잡은
것뿐이라 수작업 재검토 시 일부 추가 구제 가능성 있음(향후 과제).
