# ADR-011: 연결재무제표(CFS) 미작성 기업에 대한 OFS 폴백

## 상태
결정됨 (2026-10-10)

## 배경
2026-08-19 세션에서 재무제표 백필 범위를 fs_div=CFS(연결재무제표) 단독으로 확정했다
(`scripts/backfill_financial_statements.py` 최초 버전 docstring 참고). 당시 결정은
"분기 1개 = 호출 1건"이라는 호출 수 추정과 어긋나지 않게 하려는 단순화였고, 연결재무제표가
없는 기업은 해당 분기가 "데이터 없음"으로 남는 것을 알려진 한계로 받아들였다.

2026-10-10 검증에서 이 한계가 생각보다 크다는 것이 드러났다. 부실기업 756건 + 정상기업
2,904건, 총 3,660건의 "0분기 기업"(해당 기업의 모든 CFS 시도가 013/데이터없음으로 끝난
기업)이 1,242건(부실 568 + 정상 674)에 달했다. 이 중 924건(부실 250 + 정상 674)은 CFS
시도 자체가 전부 013으로 끝난 "완전 미복구" 상태였고, 나머지 318건은 2015-01-01 데이터
하한(FLOOR) 때문에 애초에 조회 대상 분기 자체가 없는 부실기업이었다(복구 불가, 범위 밖).

DART는 연결대상 종속회사가 없는 기업(자회사가 없는 중소형 상장사, 상장 당시 단일 법인
등)에 대해 CFS를 애초에 작성·공시하지 않는다. 이런 기업은 별도재무제표(OFS)만 존재한다.

## 검토한 대안

**1. OFS 폴백 미도입 (현상 유지)**
924개 "0분기 기업"을 그대로 둔다. 구현 비용은 없지만, 패널 구성 시 부실기업 756건 중
1분기 이상 확보분이 188건(24.9%)에 불과해 학습 표본이 지나치게 작아진다. 정상기업도
674건이 통째로 비어 negative 샘플 풀이 좁아진다.

**2. 전 기업 OFS로 통일(CFS를 버리고 OFS만 사용)**
fs_div 혼재 문제 자체를 없앨 수 있다. 하지만 이미 CFS 데이터를 확보한 2,418개 기업을 전부
OFS로 재수집해야 해 API 호출을 전면 재투입해야 하고, 종속회사가 있는 기업의 경우 OFS는
연결 실체의 위험(자회사 부실의 모회사 전이 등)을 반영하지 못해 ADR-006이 전제한 "재무비율
기반 참고 스코어"의 설명력이 떨어진다. 비용 대비 효과가 낮아 기각.

**3. CFS 우선, 없으면(013) OFS로 폴백 (채택)**
CFS를 시도해 013(데이터없음)으로 끝난 조합만 골라 OFS로 재조회한다. 이미 CFS 데이터가
있는 기업은 전혀 건드리지 않는다.

## 선택
3번(CFS 우선 + OFS 폴백)을 채택한다.

- 대상: CFS 시도 전부가 013으로 끝난 "0분기 기업" 924개(부실 250 + 정상 674)의 결측
  (corp_code, bsns_year, reprt_code) 조합 10,642건. CFS 일부만 013인 "부분 결측" 기업
  540개(부실 107 + 정상 433, 결측 조합 2,735건)는 이번 폴백 범위 밖으로 남긴다 — 이미 CFS로
  일부 데이터를 확보하고 있어 "복구 실패" 범주가 아니기 때문이다.
- 실행 결과(2026-10-10): 10,642건 중 5,283건에서 실제 OFS 데이터를 확보했고, 548개 기업이
  이 폴백으로 처음 데이터를 갖게 됐다. "0분기 기업"은 1,242건 → 694건으로 줄었다. 남은
  694건은 318건(2015년 데이터 하한으로 애초 조회 불가) + 376개 기업(CFS·OFS 모두 013, 샘플 검증
  결과 DART에 실제로 데이터가 없음 확인)로, 이 ADR의 범위에서는 더 이상 복구하지 않는다.
- `mart.financial_statement.fs_div`는 CFS/OFS 구분을 그대로 보존한다(스키마 CHECK 제약이
  이미 두 값을 모두 허용 — 변경 없음). 어떤 기업의 어떤 분기가 CFS 기반인지 OFS 기반인지
  행 단위로 항상 구분 가능하다.
- **모델 피처는 비율 지표(부채비율, 자본잠식률, 영업이익률 등) 위주로 사용한다.** CFS는
  종속회사를 포함한 금액이고 OFS는 해당 법인 단독 금액이라 절대금액(총자산, 매출액 등)을
  fs_div 혼재 상태로 직접 비교하면 스케일이 다른 두 모집단을 섞는 것과 같다. 비율 지표는
  분자·분모가 같은 fs_div 내에서 계산되므로 이 스케일 차이가 상당 부분 상쇄된다. 절대금액을
  피처로 쓰려면 fs_div별 정규화나 별도 처리가 필요하며, 이는 4주차 모델링 단계의 과제로
  남긴다.

## 선택 이유
- 이미 확보한 CFS 데이터를 전혀 재수집하지 않아 추가 비용이 최소화된다(10,642건, 일일
  한도 40,000건 대비 26.6%, 하루 내 처리 가능).
- "CFS가 없다"는 사실 자체가 해당 기업의 지배구조 특성(단일 법인, 종속회사 없음)을
  반영하는 것이므로, OFS로 대체하는 것이 임의의 추정이 아니라 그 기업에 실제로 존재하는
  유일한 재무제표를 쓰는 것이다.
- fs_div를 붕괴시키지 않고 보존해 향후 "OFS 기반 분기"를 피처 엔지니어링이나 민감도 분석
  단계에서 분리·가중치 조정할 수 있는 여지를 남긴다.

## 트레이드오프
- **548개 기업은 전적으로 OFS 기반이다.** 이 기업들은 종속회사 부실이 모회사 재무제표에
  반영되지 않는 상태로 패널에 들어간다. 종속회사를 통한 위험 전이가 실제로 존재하는
  기업(지주사 구조 등)이 이 548개 안에 섞여 있다면, 해당 기업의 리스크가 체계적으로
  과소추정될 수 있다. 현재는 CFS 부재 여부로만 OFS 대체를 결정했고, 종속회사 유무를
  별도로 검증하지 않았다 — 향후 과제.
- CFS와 OFS가 혼재된 패널은 "같은 피처명, 다른 모집단 성격"이라는 암묵적 이종성을
  내포한다. 비율 지표 위주 설계로 완화하지만, 완전히 제거되는 것은 아니다(예: 부채비율도
  연결 종속회사의 부채 구조가 모회사와 크게 다르면 CFS/OFS 간 분포 차이가 남을 수 있음).
- 376개 기업(CFS·OFS 둘 다 013)은 이 ADR 이후에도 재무 피처가 전혀 없는 상태로 남는다.
  패널 구성 시 정상 모집단에서 제외 처리한다(후속 작업, 이 ADR 범위 밖).
- 이번 폴백은 "CFS 전부 013"인 기업만 대상으로 했다. CFS 일부만 013인 540개 기업(부실 107 +
  정상 433)의 결측 분기 2,735건은 OFS로 보완하지 않았다 — 해당 분기만 떼어놓고 보면 여전히
  결측이며, 향후 필요시 같은 메커니즘(`--ofs-fallback`)을 부분 결측 기업까지 확장해야 한다.
  그중 **부실기업 107개의 결측 조합 367건은 미처리 상태로 남아있고, 이번 OFS 폴백의 다음
  단계 후보다** — 부실 라벨의 feature window 완전성에 직접 영향을 주므로 부분 결측 540개
  전체보다 우선순위가 높다.
